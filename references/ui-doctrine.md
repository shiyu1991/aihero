# UI 生成守则全文（按需加载）

> 本文件是 SKILL.md 规则 11/12 的全文承载。**触发时机**：任何 UI/产品任务动手前（总纲+⓪-⑩）、交付验证前（⑪-⑫）、改素材策略时（规则 11）。SKILL.md 只留骨架。

## 交付 Checklist（两级 Gate，按序执行）

**演示 Gate（每次交付必过，按序）：**
1. 冒烟测试全绿（字符串断言）
2. `--dump-dom` 渲染节点计数兜底（防 JS 错误静默）
3. 溢出双验法三档（375/768/1440，几何探测为准）
4. 核心交互走查 ≥3 项（tab/加购/返回顶部级）
5. 分区截图 vision 复核（禁整页缩略判读）

**产品 Gate（公网部署/真实产品追加）：**
6. ⑪⑧ 性能跑分（Lighthouse：LCP<2.5s / CLS<0.1 / 单文件≤1.5MB / 无长任务）+ axe-core 无障碍跑分
7. ⑪① 真机走查（android-emulator / ios-simulator）
8. ⑪⑥ SEO 全套（canonical/og/JSON-LD/sitemap）+ 按需装 SEO skill 候选
9. ⑫ 状态完备性五态对照 anti-ui-slop audit 逐一过
10. 条件增强项（若适用）：主题切换 / 国际化（见下方专节）

## 规则 11 素材与竞品调研（UI/产品类请求动手前必跑，一句话小改可跳过）

像产品经理一样先调研再创作——

- **素材四源，必须真寻、真参考、真使用（只看不用于不算）**：
  ① **竞品实站**（>UI 画廊，人家已打磨完善；用画廊必须进其品类相关内容页，不做关键词泛查）
  ② **GitHub 等免费站**（UI 组件/图标/插画/模板库，MIT/免费许可优先）
  ③ **ui-ux-pro-max 风格库**
  ④ **SVG 插画守则（2026-11-07 用户定）**：hero 氛围/空态/装饰/品牌感等插画位**优先成熟 SVG 矢量插画库，自绘 SVG 仅兜底**（极简符号或库无对应题材时）；**只认矢量源、光栅插画不选**（质量难判，真实感图像一律走 image-search 配图管线）；已验证源：unDraw（免费商用免署名/扁平通用）、Open Doodles（CC0/手绘涂鸦）、Humaaans（CC BY 需署名/人物组合）、DrawKit（免费集可商用/精致矢量）、Storyset（需署名 Freepik/可配色场景）、papercut-box-art（MIT/剪纸国潮）；题材匹配优先（国潮→papercut 系），来源与许可写进铭牌
- **配图是食材级要素（2026-11-06 西餐厅页教训）**：离线单文件也必须内嵌真实图像——image-search 找图 → 下载 → PIL 压缩（宽≤960、q≈52、总≤800KB）→ base64 data-URI 注入（占位符+脚本替换，不经上下文）；"零外部依赖"不是无图借口；图片来源与许可写进页脚铭牌
- 离线单文件场景下，用真实产品的数据结构组织演示数据；**内容与动效趋势都要调研**（动效优先 hero、滚动编排、微交互、材质层次）

## 规则 12 UI 生成守则

**总纲（2026-11-06 多轮 A/B 实证后用户定）**：素材必寻必用（UI 素材/竞品实站/GitHub 免费库）、配图是要素、布局实用美观大气（高空间利用率，拒绝挤压、层叠、超出无法滚动）、高保真、高交互体验、符合场景的动效/插图、背景、配图。UI/产品任务在拆解时必须整体注入本守则，逐项对照执行，**缺项即不合格**。

- **⓪ 新项目先拷问**：全新 UI/产品请求（非一句话小改）动手前必须先问 3-5 个关键问题——受众与调性、明暗风格偏好、内容重点、转化目标、有无参考站点、**内容供给（文案/图片/数据谁来给：用户提供 vs 调研生成 vs 占位——内容缺失是真实项目头号延期源，2026-11-07 用户补）**、**验收方式（怎么算做好：交付形态=离线文件/公网 URL/指定域名，验收人是谁——决定 ⑪④ 交付段走法，2026-11-07 用户补）**；用户答完才排链。**禁止替用户编造产品设定**（品牌/业务/文案全是自创=返工之源；天气、餐厅、旅游三案实证）；本条是 UI 动工前的设定确认而非项目入口，创建类请求先走第 0 步的 grill-me
- **① 风格判断**：工具/信息类页面走品类正统（用户期待 > 新颖，如天气页就要天空渐变+毛玻璃+大温度）；品牌/门面类页面才追求差异化。**配色基调默认开朗光明**：整体主题尽可能选明亮底色，不做阴暗选择；深色仅在用户点名要求、或题材强需求（如夜间酒吧/恐怖题材）时采用，且须在交付说明里讲清为什么用深色；深色可以作局部点缀（照片节/页脚/对比带），不当整页基调
- **② PM 调研**（规则 11 素材四源 + 配图）
- **③ 内容密度与高保真**：信息饱满、题材专属素材、真实数据质感（细节完整可推敲）；"安静"指装饰克制 ≠ 内容单薄
- **④ 编辑**：去重合并，不平行罗列
- **⑤ 动效与交互**（执行深度 = 高级感，**无动效直接判不合格**）：入场编排、滚动错峰、背景氛围动效（雨/云/光粒子按题材）、数字滚动、条形生长、路径描边、悬停微交互、动效回答操作、可点击组件（灯箱/展开/切换）
- **⑥ 转化机制**（有行动目标时）：倒计时/余量/信任标记
- **⑦ 工程底线**：reduced-motion 全覆盖、动态内容容器定高防 CLS、审计清单过一遍
- **⑧ 交付纪律**：改被批评的**原文件**（用户刷新即见），不写新文件名；skill/规则改动须用户认可效果后再入库推送
- **⑨ 版式工艺**：**拒绝挤压**（窄屏断点降列不压扁、文字不硬折行）；**拒绝错误层叠**（装饰不盖信息、高亮不遮数据）；**拒绝超出无法滚动**（横向内容必须可滚或有断点收纳）；贴边要有暗示（横滑区渐隐提示）；滚动决策（关键信息吸顶随行）；**长页可加返回顶部按钮**（非必须：滚过首屏后浮现，与吸底条错位不遮挡，reduced-motion 下直接跳转）；**高空间利用率**（宽屏并排减竖向占用）
- **⑩ 风格分类推荐**：动手前从需求分析风格分类——用 ui-ux-pro-max 风格库检索（查询词=品类+平台+气质，2~5 词，一种主导意图；如"weather consumer app glass translucent"→Liquid Glass/Apple 系），**给用户看：推荐风格+一句理由+2 个备选，且每条必须附至少一个可打开的参考地址**（官方规范优先，其次案例画廊）；用户点名风格时绝对优先；检索不中就明说"无验证命中"再给通用建议，不硬凑。注意：查询词决定命中质量（"apple ios minimal"会带偏去瑞士极简，"glass translucent"才命中 Apple Liquid Glass）
  - 参考地址锚点（已验证可达；无映射时现场搜索验证再给，找不到就明说）：Liquid Glass/Apple 系→ developer.apple.com/design/human-interface-guidelines/materials；Brutalism→ brutalistwebsites.com；Bento Grid→ bento.me；通用灵感→ godly.website / awwwards.com / land-book.com / mobbin.com（App 界面）
  - **品牌规范源（2026-11-07 实证入册）**：用户点名品牌或需品牌级精度时，从 VoltAgent/awesome-design-md（★126k，成熟品牌 DESIGN.md 集合）取对应文件作 grounding——比风格库检索更准；自建/长期项目按 google-labs-code/design.md（★29k，格式规范）沉淀自己的 DESIGN.md（与 ui-ux-pro-max --persist 的 MASTER.md 同构）；按需取用不克隆不装 skill
- **⑪ 验证与交付（完整流程 v2）**：高保真页面交付前必过「三验一交」，执行顺序见顶部 Checklist——
  ① **多断点截图**：375/768/1440 三档 headless 截图 + 分区 vision 复核（挤压/层叠/溢出在窄屏最易暴露，只截桌面=没验版式）；产品级加**真机走查**（android-emulator / ios-simulator 插件：模拟器实机渲染+触摸，检验 sticky/safe-area/滚动惯性等只有真机才暴露的问题）
  ② **交互走查**：web-gui-tester 真浏览器点击/滚动断言（tab 切换、加购计数、返回顶部、键盘焦点序）；**执行配方（2026-11-07 实证）**：smooth-scroll 页面 Playwright 语义点击易超时 → 「JS instant 滚动定位元素中心 + CUA 坐标点击」
  ③ **执行验证**：冒烟字符串断言必须配 `--dump-dom` 渲染节点计数兜底（防 JS 语法错误静默——年货站实证：多一个 `}` 冒烟仍全绿但页面全空）
  ④ **交付默认 site-deploy 出 URL**（移动端扫码即验），截图存档
  ⑤ **环境坑（走查实证）**：CLI `--window-size` 有 ~500px 最小窗宽钳制——<500px 断点截图会被裁切出假「溢出」，必须走浏览器自动化 `setViewportSize`；IAB 底缘约 30px 有指针死区、3 万像素级长页会拖垮标签页，关键交互点击宜在桌面视口/新标签验证；**「字符串存在≠行为绑定」**：按钮在脚本之后解析会让 getElementById 静默返 null（冒烟全绿但行为失效；**同一坑两次实证**：toTop 按钮、吸底条计数——凡 body 尾部新增元素的脚本引用，必须 DOMContentLoaded 延迟绑定或 handler 内实时查询），交互走查是唯一防线；**IAB 标签页 reload 后 CUA 指针事件失效**（reload 后点击无响应时换新标签页，勿反复重试）
  ⑥ **交付增强——SEO/分享卡（条件触发）**：触发条件=site-deploy 出公网 URL 且页面需被分享/收录；清单=canonical、og:title/description/image/type（og:image 必须绝对 URL，部署后才能填）、twitter:card、按页面类型的 JSON-LD、多页站加 sitemap.xml+robots.txt、i18n 站加 hreflang；单页演示默认只做 og 分享卡；离线单文件阶段一律不做（SPEC 边界），不为此装新 skill（清单属基线职责）；**真实产品触发时按需装已验证候选（挂候选不预装）**：claude-seo（AgriciDaniel，★27k，26 子技能+19 子代理，技术 SEO 深度审计）、marketingskills（coreyhaines31，★59k，营销全家桶含 CRO/文案/分析，作者知名）、geo-seo-claude（★11.5k，GEO 向=让 AI 搜索引用，2026 流量新入口）、open-seo-mcp-skills（★8.9k，关键词/排名追踪，需外部数据 API）
  ⑦ **溢出检查（双验法）**：每个断点必跑——**几何探测为准**（浏览器自动化 setViewportSize 真视口下，只读遍历 `rect.right > clientWidth + 1` 的元素并按 类名+right+width 列出元凶清单；主判据用元素 rect 而非 scrollWidth，因 `overflow-x: clip/hidden` 下 scrollWidth 未必如实反映）＋**分区截图为证**（整页缩略误报高，须裁关键区复核）；发现超宽→修 min-width/固定宽/grid minmax 后复测归零；严禁用 CLI `--window-size` 判溢出（最小窗宽钳制出假象，见⑤）
  ⑧ **性能预算（条件触发）**：公网部署/产品级交付时跑 headless Lighthouse——预算基线：LCP<2.5s、CLS<0.1、总体积（单文件含图 ≤1.5MB）、无长任务阻塞；**并跑 axe-core 无障碍扫描**（产品级）；演示项目跳过
- **⑫ 状态完备性**：**异步数据（fetch/网络图/接口）五态必齐，纯内联数据（单文件演示/base64）免做**——①Loading：操作按钮加载中保留文案+spinner、防重复提交，加载提示以「…」结尾；②骨架屏：内容位用**同构布局**的 Skeleton/Shimmer 占位防 CLS（容器定高/aspect-ratio 占位同理）；③空状态：引导文案+下一步动作，不留白板；④错误态：内联展示+重试入口，不只 toast；⑤成功/禁用态：即时反馈（实证：领券→已领取✓+disabled）；验收时对照 anti-ui-slop audit 的 states 检查项逐一过

## 条件增强项（产品级可选，2026-11-07 用户定）

**触发原则**：用户点名或产品明确需要才做，演示项目一律跳过；均为基线职责，不装 skill。

### 主题切换（明/暗多主题）
- **前提**：设计令牌走 CSS 变量（`--color-*`），双主题=变量换组；12-① 的「默认明亮」仍是基调守则，主题项只管"需要多主题时怎么做"，冲突时 ① 优先
- 清单：`prefers-color-scheme` 自动跟随 + 手动切换器（日/月图标）+ `localStorage` 记忆；`color-scheme: light dark` 声明与 `theme-color` 双值；暗色下重查对比度（web-design-guidelines 暗色条目）；图片/插图在暗色下的处理策略（降亮度滤镜或双套）

### 国际化（i18n）
- 清单：文案外置（i18n 资源表，不硬编码在组件里）；`lang` 属性随语言切换；日期/数字用 `Intl.DateTimeFormat` / `NumberFormat`（禁硬编码格式）；多语言站加 `hreflang`（与 ⑥ 联动）；RTL 语言（阿语等）需 `dir` 切换与逻辑属性（`margin-inline` 替代 `left/right`）；字体栈按语种适配（CJK/阿拉伯/拉丁）

### 其余产品级增强（维持跳过清单语义）
埋点分析、安全审查（CSP/外链 noopener/输入消毒）——产品必补，演示跳过，按需逐项展开为专节。
